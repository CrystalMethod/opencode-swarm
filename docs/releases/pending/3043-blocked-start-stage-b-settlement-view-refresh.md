## Fixed

- **Blocked-start settlement-wedge recovery now refreshes the recovering session's in-memory workflow view (issue #3043, follow-up to #3032/#3038).** The two blocked-start recovery writers — the architect-only `recover_stage_a_task` tool and the `/swarm recover` settlement-wedge repair — advanced the durable workflow evidence (`stage_a_passed` with the `settlementRecovery` marker) without updating any session's in-memory `taskWorkflowStates` map. A session whose map legitimately held `blocked` (the `task_blocked` terminal writes durable and map together) stayed wedged after recovery: reviewer/test_engineer dispatch was admitted from the durable evidence, but the Stage B settlement loop filtered on the stale map, the #3038 at-or-above guard correctly refused to repair `blocked` consumer-side, and every APPROVED/PASS verdict was silently skipped — no `gates.reviewer`/`gates.test_engineer` write, no advisory, no completion path short of a fresh session. Both writers now refresh the recovering (or `/swarm recover`-invoking) session's view from the durable snapshot they just wrote or verified, via the new shared `workflow/session-view.ts` helpers: the view is refreshed when absent, `rework_required`, `blocked`, or lagging durable; barrier-ahead (`tests_run` over an earlier durable state) and terminal (`closed`/`complete`) views are never downgraded. The idempotent no-op re-run of `recover_stage_a_task` also self-heals a re-diverged view with zero durable writes, and a `/swarm recover` re-run now un-wedges already-recovered tasks for the invoking session (before this change neither surface did). The consumer-side `isRepairableStageBView` guard is intentionally unchanged — a `blocked` view in a session that did NOT run the recovery (cross-session divergence) is still never repaired automatically; run the recovery in that session or start a fresh one. `update_task_status`'s recovery-leg sync now shares the same view-application helper, so the cleared bookkeeping set (`stageBCompletion`, council maps, workflow cache) can never drift between the two surfaces.
