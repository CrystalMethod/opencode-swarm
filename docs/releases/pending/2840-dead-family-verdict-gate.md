# PR-review dead-family verdict gate (issue #2840)

## What

- **Dead-family disclosure now gates the verdict.** A PR_REVIEW completion whose durable trigger-eval receipt carries any disclosed `coverage_degradations` entry (liveness-terminal dead family or coverage-quality degradation) can no longer emit verdict `APPROVE`. `allowedPrReviewReportVerdicts` gains an optional `options.disclosedCoverageDegradation` third argument; when set on a `COMPLETE` settlement it constructs the `{quality:'degraded', disclosed:true}` coverage the finding policy already maps to `DEGRADED_DISCLOSED` → `['REQUEST_CHANGES','INCOMPLETE']`. This closes the gap #2836 opened: the disclosure existed on the receipt but nothing on the verdict path read it, so a 6/6-base review with a liveness-dead micro family could still approve — contradicting the documented "a dead family is never APPROVEable" property.
- **Wired at every verdict decision point.** Both completion gates (reducer-owned finalization + preflight + post-ladder finding-policy check), the finalization BLOCKED message (new typed rejection `degraded_disclosure_cannot_approve` with a degradation-naming operator message), and both read-only report projections (`readPrReviewFinalFindingPolicyForReport`, terminal-report `allowedVerdicts`). A call-site wiring ratchet test pins the five production call sites and requires each to pass the flag, so a future unwired caller cannot merge (the exact defect class that produced this bug).
- **Shared bounded receipt reader.** New `src/background/pr-review-trigger-receipt-reader.ts` owns the path-validated, byte-capped, strictly-parsed receipt read previously inlined in the inventory pass. Unset receipt path ⇒ no degradation with zero filesystem access (pre-#2836 receipt-less runs are unaffected); a set-but-corrupt receipt BLOCKs exactly like the inventory always did.
- **TOCTOU cross-check on dead-family admission.** `write_pr_review_trigger_eval` no longer admits a lane as a dead family when its durable record already holds a `prReviewResultReceipt` (the receipt can land as the presumed-stale liveness sweep fires, or later via parentRepair) — such a row fails closed on the provenance chain instead of mislabeling real findings "presumed host abandonment". Admission additionally re-reads the record fresh immediately before deciding, narrowing the race to the receipt write itself (documented residual).
- **Reducer matrix consistency (issue #2512).** `coverage_finalization_requested` carries `disclosedDegradation`; the reducer rejects `COMPLETE` + `APPROVE` under it with `degraded_disclosure_cannot_approve`, mirroring the production matrix.

## Why

Issue #2840 (found by an independent swarm-pr-review of PR #2836): the #2835/#2836 dead-family disclosure was recorded on the receipt but consumed only by the candidate-inventory pass; the verdict derivation (`kind` from the six base dimensions, `allowedPrReviewReportVerdicts` with hardcoded `provenance:'valid'`) never saw it. The intended `DEGRADED_DISCLOSED` policy branch (issue #2491) had no production constructor. Newly reachable since #2836; no mechanical backstop existed (the SKILL.md join-barrier instruction was prose-only).

## Notes

- Any non-empty `coverage_degradations` forces the degraded matrix (per the issue's remediation), not only liveness-terminal rows — subclassifying by parsing `reason` strings would be fragile, and any disclosed degradation honestly downgrades the review's coverage claim.
- PARTIAL and NO_COVERAGE rows are unchanged (PARTIAL already excluded APPROVE; NO_COVERAGE stays forced-INCOMPLETE through its `{quality:'none'}` mapping).
- Residuals recorded on the issue: retry-exhaustion enforcement needs new persisted attempt-counter state (tracked separately); the trigger-eval admission race window between the fresh re-read and the receipt write would need evidence-lock integration to close fully.
- Guardrails: four new regression suites pin the matrix in both directions (exact-array assertions), the gate-level BLOCKED behavior, both projections, the TOCTOU refusal + control, and the call-site wiring ratchet (25 tests).
